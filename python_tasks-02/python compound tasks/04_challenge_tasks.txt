LEVEL 4 — CHALLENGE TASKS

Task 17 — Palindrome Practice
Ask for a word.

Convert to lowercase.
Reverse it using slicing.

If original == reversed:
    Print "Palindrome"
Else:
    Print "Not a Palindrome"

Examples:
madam -> Palindrome
python -> Not a Palindrome

Task 18 — Name Initials
Ask:
- First name
- Middle name
- Last name

Using indexing, print initials.

Example:
Karthikeya Sai Rao

Output:
K.S.R

Also print full name in title case.

Task 19 — Promo Code Validator
Create:
valid_code = "PYTHON10"

Ask:
- Promo code
- Product price

Convert entered promo code to uppercase.
Convert price to float.

If code matches:

Else:

Print final price.
